# Dataset

Este proyecto usa el dataset "Smart Meters in London":
https://www.kaggle.com/datasets/jeanmidev/smart-meters-in-london

## Cómo obtenerlo
1. Descargar desde el link de Kaggle.
2. Copiar la carpeta `hhblock_dataset/` y el archivo `informations_households.csv` a esta carpeta (`notebooks/data/`).
3. Ejecutar `notebooks/eda_limpieza.ipynb`.
